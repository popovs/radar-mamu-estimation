# Abundance and Distribution of Marbled Murrelets in British Columbia
## Estimating population size using radar counts

This repository contains all the code and statistical/geospatial analyses used for an upcoming publication on marbled murrelets in BC. This project comes bundled with a `renv` file in order to reproduce the package environment that was in place while running these analyses, so the code should work out-of-the-box.

## data

This folder contains the data used in this analysis, including the raw radar count survey data and conservation region boundaries.

## R

This folder contains the entire R pipeline necessary to reproduce the results of the paper.
